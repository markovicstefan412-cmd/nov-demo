# NOV · Not Ordinary Vision (demo)

Demo web shop za NOV, prve AI naočare kod nas. Porudžbina se šalje kroz Instagram DM.

Uživo: https://markovicstefan412-cmd.github.io/nov-demo/

Statičan sajt: HTML, CSS i vanilla JavaScript, bez frameworka i bez build koraka.

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/, assets/video/
```

Lokalno pokretanje (hero video se učitava preko `fetch()`, pa treba server):

```
python -m http.server 8080
```

Pre prave objave: upisati cene umesto `[CENA]` i način plaćanja u FAQ.

Dizajn i izrada: [Vektor Code](https://www.vektorcode.com)
